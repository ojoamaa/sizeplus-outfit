SIZEPLUS OUTFIT — CLIENT REVIEW PROTOTYPE V0.6.1

Purpose
This package is the frozen client-review baseline for Sizeplus Outfit. It is intended for UAT/consent before production integrations.

Important
- Online payment is DEMO ONLY. No real Paystack charge is processed.
- Product and stock data are sample/demo data unless replaced by the boutique.
- This review build should not be used as the live commercial store.
